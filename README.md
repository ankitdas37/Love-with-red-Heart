# ❤️ Love with Rad Heart

An animated little love note made with plain HTML, CSS, and JavaScript. Watch a character draw in, send a stream of hearts across the card, and reveal the final message.

## ✨ The experience

- A hand-drawn character animates into view.
- A trail of heart particles gathers into a big heart.
- The “Love You” message fades in when the heart is complete.
- No frameworks, build tools, or package installs required.

## 🚀 Run it

Clone or download this repository, then open `index.html` in a modern browser.

For a local server, run this from the project folder:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## 💝 Make it yours

- **Change the name:** edit the `Binu` text inside `index.html`.
- **Change the message:** edit the `Love You` heading in `index.html`.
- **Adjust the look:** update colors, typography, layout, and animation styles in `style.css`.
- **Shape the heart:** edit the `pattern` array near the top of `script.js`. Each `0` marks a heart particle.
- **Tune the animation:** adjust the particle positions, `cellSize`, and timing values in `script.js`.

## 📁 Project files

| File | Purpose |
| --- | --- |
| `index.html` | Card markup, character illustration, and message |
| `style.css` | Layout, colors, and drawing/fade animations |
| `script.js` | Heart-particle pattern and animation sequence |
